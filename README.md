# Smart Expense Tracker

## Overview
Smart Expense Tracker is a Python application that helps users track and analyze their daily expenses.

## Problem
Many students and individuals do not track their expenses regularly, which leads to overspending and poor financial management.

## Solution
This project provides a simple system where users can record expenses and analyze their spending.

## Features
- Add new expenses
- View all expenses
- Calculate total spending
- Analyze spending by category
- Visualize data using graphs

## Technologies Used
- Python
- JSON
- Matplotlib

## Project Structure

main.py → Main menu and program control  
expense_manager.py → Handles adding and viewing expenses  
analytics.py → Performs spending analysis  
data.json → Stores expense data  

## How to Run the Project

1. Install Python
2. Install required library

pip install matplotlib

3. Run the program

python main.py
